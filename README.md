# Stephabit Board CMS

## 1. 프로젝트 소개
개인 블로그 운영자를 위한 게시판형 콘텐츠 관리 시스템입니다.

## 2. 개발 목적
단순 CRUD 게시판을 넘어, 실제 블로그 운영에 필요한 검색, 태그, 댓글, 관리자 기능을 구현했습니다.

## 3. 기술 스택
Java 17, Spring Boot, MariaDB, Thymeleaf, GitHub

## 4. 주요 기능
- 회원가입 / 로그인
- 게시글 CRUD
- 댓글
- 카테고리 / 태그
- 검색 / 페이징
- 관리자 대시보드

## 5. ERD
이미지 첨부

## 6. 화면 설계
메인, 목록, 상세, 작성, 관리자 페이지 캡처

## 7. 실행 방법
로컬 실행 명령어, DB 설정 방법

## 8. 트러블슈팅
개발 중 겪은 문제와 해결 과정

## 9. 회고
아쉬운 점과 개선 계획
